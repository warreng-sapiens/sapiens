# Mettre Sapiens sur GitHub Pages (vraie app iPhone / iPad)

1. Ouvre ton dépôt `sapiens` sur github.com.
2. « Add file » → « Upload files ».
3. Dépose **tout le contenu** de ce dossier : `index.html`, `sw.js`, `manifest.webmanifest`, les 3 icônes `icon-*.png` et le dossier `splash`.
4. « Commit changes ». Attends 1 à 2 minutes.
5. Sur ton iPhone ou ton iPad, ouvre https://warreng-sapiens.github.io/sapiens/ dans **Safari**.
6. Bouton **Partager** → **« Sur l’écran d’accueil »** → **Ajouter**.

Ensuite, pour chaque mise à jour, il suffit de remplacer `index.html` et `sw.js`.
L’app affichera « Une nouvelle version de Sapiens est prête » : touche « Mettre à jour ».
